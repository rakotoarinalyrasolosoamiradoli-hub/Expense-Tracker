# Expense Tracker 💸

A simple and interactive expense tracking application built with **HTML, CSS, and Vanilla JavaScript**.

Expense Tracker allows users to record, manage, and visualize their daily expenses through a clean and modern interface.

## ✨ Features

- **Add Expenses:** Record expenses with a description, amount, category, and date.
- **Expense History:** View all recorded expenses in a table.
- **Delete Expenses:** Remove expenses when needed.
- **Total Expenses:** Automatically calculate the total amount spent.
- **Date Sorting:** Display expenses from newest to oldest.
- **Data Persistence:** Save expenses using the browser's Local Storage.
- **Data Visualization:** Display daily expenses and the average daily spending using Chart.js.

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (Vanilla JS)
- Local Storage API
- Chart.js

## 📊 Expense Statistics

The application uses Chart.js to visualize daily expenses and display the average daily spending.

## 💾 Data Storage

Expenses are stored locally in the browser using the Local Storage API. No external database is required.

**Note:** Clearing the browser's Local Storage will remove saved expenses.
